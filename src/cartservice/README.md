# Cart Service

The Cart service provides functionality for managing user carts and items within those carts.

## Proto Files

Proto files are placed inside `src/cartservice/src/protos` after running `genproto.sh`:

```
./genproto.sh
```

Original proto files should be placed at `../../protos`	before executing the script.

## Build

From `src/cartservice`, run:

```
docker build ./src
```
