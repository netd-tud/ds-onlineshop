# Payment Service

The Payment service provides functionality for processing payments from users and verify the Payment details.

## Proto Files

Proto files are placed inside `src/paymentservice/proto` after running `genproto.sh`:

```
./genproto.sh
```

Original proto files should be placed at `../../protos` before executing the script.

## Build

From `src/paymentservice`, run:

```
docker build ./
```
