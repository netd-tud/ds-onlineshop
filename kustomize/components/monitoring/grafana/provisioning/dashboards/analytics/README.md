# Analytics Dashboards
These Dashboards visualize the analytics metrics calculated by the Kafka → Flink processing pipeline.
They contain a set of example statistics that can be derived from user activity.

## Order
The Order Dashboard showcases metrics derived from events published by the checkoutservice.

Excerpt of metrics:
- `Average order volume per hour` for each region/currency to showcase timezone influence and regional differences
- `Total revenue per currency`
- `Product views` to add to cart conversion

## Product views
The product views dashboard showcases metrics related to user interactions with products.

Excerpt of metrics:
- `Views per product` to showcase product trends
- `Product recommendations`
